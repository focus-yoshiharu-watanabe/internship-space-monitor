# スペース見守りモニター

カメラに映った人をAIが見つけて、**定員オーバー**と**離席**を画面に知らせるアプリです。
カメラ・AI・画面表示の部分はできています。みなさんが書くのは、**人数を数える関数**と**自分のルールの関数**です。

---

対応しているのは **Windows の PC** です（Jetson は担当者が準備します）。

## 1. セットアップ（最初に1回だけ）

1. GitHub のこのページで **Code → Download ZIP** を押してダウンロード
2. ダウンロードした ZIP を右クリック → **プロパティ** →「**許可する**」にチェック → OK（これをしないと Windows に止められることがあります）
3. ZIP を展開して、フォルダの中の `setup.bat` をダブルクリック
4. 「DONE」と出たら完了（数分かかります）

※ 事前に Python（3.10 以上）が入っている必要があります。

## 2. 起動

`run.bat` をダブルクリック。自分が映って**緑の枠**が出れば成功です。`q` キーで終了します。

カメラは PC に付いているもので大丈夫です。**テスト中は PC を動かさない**でください（画角が変わると、直したことが効いたのか分からなくなります）。

カメラの代わりに動画で試すときは、`app.py` の `SOURCE` に動画のパスを書きます（例：`SOURCE = "videos/test.mp4"`）。

## 3. 画面の見方

| 表示 | 意味 |
|---|---|
| 緑の枠 | AIが見つけた物（名前と自信の度合い 0〜1） |
| 青い四角 | 見守るゾーン（`ZONE`） |
| 左上「現在 ○人」 | `count_people` が返した人数 |
| 画面のふちの色・下のメッセージ | ルールが返した Alert |
| 右下 `x= y=` | マウスの位置の座標。`ZONE` を決めるときに使う |

## 4. ファイルと担当

| ファイル | 担当 | 中身 |
|---|---|---|
| `common.py` | **2人で** | `count_people`：ゾーンの中の人数を数える |
| `capacity.py` | 定員カウント担当 | `judge_capacity`：定員を超えたら警告 |
| `absence.py` | 離席検知担当 | `judge_absence`：一定時間いなかったら通知 |
| `app.py` | 土台 | **上の「設定」欄だけ**触ってOK |
| `detector.py`・`models/` | 土台 | AIの部分。触らない |

自分のルールを動かすには、`app.py` の `RULES` を自分の担当のものにします。

```python
RULES = [judge_capacity]   # 定員カウント担当
RULES = [judge_absence]    # 離席検知担当
```

## 5. 作業のルール

- **15分詰まったら相方に聞く。30分詰まったら担当者に聞く**
- 動いたら、ファイルをコピーして保存する（例：`capacity.py` → `capacity_ok1.py`）
- AI（Claude Code）に頼むのは**自分の関数1つだけ**
- AIが出したコードは「この行は何をしてる?」と**聞き返してから使う**
- エラーが出たら、AIに貼る前に「どこで何が起きたか」を口で一言説明してみる

## 困ったとき

| 症状 | 対処 |
|---|---|
| `setup.bat` で「Python not found」 | Python が入っていません。担当者を呼んでください |
| 「カメラ 0 を開けません」／映像が真っ黒・白黒 | `.venv\Scripts\python find_camera.py` で番号を調べて、`app.py` の `SOURCE` を変える（顔認証用のカメラが 0 番になっている PC があります） |
| カメラが映らない（番号を変えてもダメ） | Windows の設定 → プライバシーとセキュリティ → カメラ で「デスクトップアプリがカメラにアクセスできるようにする」をオン |
| 画面に「○○ でエラー」と出る | 自分のコードで例外が起きています。**ターミナルに詳しい内容**が出ているので、それを読む（AIに貼ってもOK） |
| 「返り値が約束の形ではありません」 | Alert の形 `{"rule": ..., "level": ..., "message": ...}` になっているか確認 |
| 「level '○○' は LEVEL_COLORS にない」 | 2人で決めた level の名前と、`app.py` の `LEVEL_COLORS` がずれています |
| 動きがカクカクする | PCの性能によっては普通です。気になる場合は担当者に言えば、軽いAIモデルに切り替えます |
| 日本語が □ になる | 担当者を呼んでください |

## テスト動画の撮り方

```
.venv\Scripts\python record_video.py 0 videos/test.mp4
```
`r` で録画開始／停止、`q` で終了。撮った動画を `SOURCE` に書くと、何度でも同じ映像で試せます。
